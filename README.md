# Crimson Noir

A darker, cleaner skin for DreadVault. It sits on top of the site's **Dark red** theme and refines it: warm near-black background, rounded cards, softer contrast, and tidier forums, chat, profiles and rules pages.

## Install

1. Go to **Settings → External CSS stylesheet**.
2. Paste:

   ```
   https://cdn.jsdelivr.net/gh/DV-skin/skin@v1.0/crimson-noir.css
   ```

3. Keep **Theme** on **Dark red**, save, then press Ctrl+F5.

To remove it, clear the field and save.

## Updates

Each release has its own version tag (`@v1.0`, `@v1.1`, …). Your link stays on the version you installed until you change it to a newer one.
