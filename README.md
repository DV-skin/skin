# DreadVault skins

Custom stylesheets for DreadVault. Each one loads on top of the site's own theme.

## How to install a skin

1. Go to **Settings → External CSS stylesheet**.
2. Paste the skin's link from below.
3. Set **Theme** as the skin suggests, save, then press Ctrl+F5.

To remove it, clear the field and save.

## Crimson Noir

A darker, cleaner take on the **Dark red** theme: warm near-black background, rounded cards, softer contrast, and tidier forums, chat, profiles and rules pages.

```
https://cdn.jsdelivr.net/gh/DV-skin/skin@v1.0/crimson-noir.css
```

Theme: **Dark red**

### Crimson Noir (clear artwork)

The same skin, but the TMDB header art on torrent pages shows unblurred, with a soft shadow behind the text to keep it readable.

```
https://cdn.jsdelivr.net/gh/DV-skin/skin@crimson-noir-clear-v1.0/crimson-noir-clear.css
```

Theme: **Dark red**

## THC Nostalgia

By **scaryi68**. For the nostalgics: the same colours as the old THC. Deep purple and plum panels with acid-green text, a custom site logo and retro forum icons.

```
https://cdn.jsdelivr.net/gh/DV-skin/skin@thc-nostalgia-v1.0/thc-nostalgia.css
```

Theme: **Material design 3 dark**

Tweaks are welcome, so feel free to build on it.

## Updates

Each skin's link points at a fixed version. You stay on that version until you change your link to a newer one.
